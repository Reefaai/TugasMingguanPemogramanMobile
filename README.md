# Tugas Mingguan Pemrograman Mobile

Repository ini berisi kumpulan tugas mingguan mata kuliah **Pemrograman Mobile**.

---

## 📌 Struktur Branch Tugas
Seluruh tugas mingguan disimpan dan dikelola pada **branch terpisah** untuk menjaga kerapian struktur proyek:

* **`tugas-10`** (Logistics Tracker App)
  * **Fitur & Teknologi**:
    * Integrasi REST API Pelacakan Resi dengan **Retrofit 2** & **OkHttp Logging Interceptor**.
    * **Smart Fallback Interceptor** (Auto-Retry & Mock Data Fallback 5 resi simulasi).
    * Tampilan UI/UX Modern **Material Design 3** bertema **Soft Sea Blue**.
    * Pengelolaan State UI: *Loading*, *Success*, *Server Error (404)*, dan *Network Failure*.
* *(Branch tugas mingguan lainnya akan ditambahkan pada branch masing-masing)*

---

## 🚀 Cara Mengakses Branch Tugas

Untuk melihat atau menjalankan tugas pada branch tertentu:

```bash
# 1. Clone repository
git clone https://github.com/Reefaai/TugasMingguanPemogramanMobile.git
cd TugasMingguanPemogramanMobile

# 2. Lihat semua branch yang tersedia
git branch -a

# 3. Beralih ke branch tugas (contoh: tugas-10)
git checkout tugas-10
```
